# TransitOps Frontend

A React + Vite frontend for TransitOps, focused on fleet operations, dispatch workflows, safety tracking, and financial visibility.

## Features
- Authentication with protected routes
- Role-based access control for fleet workflows
- Dashboard and operational modules for vehicles, drivers, trips, maintenance, and fuel logs
- Responsive UI with reusable layout components

## Tech Stack
- React
- Vite
- React Router
- Tailwind CSS
- ESLint

## Project Structure


## Getting Started
1. Install dependencies:
   `npm install`
2. Start development server:
   `npm run dev`
3. Build for production:
   `npm run build`
4. Preview production build:
   `npm run preview`
